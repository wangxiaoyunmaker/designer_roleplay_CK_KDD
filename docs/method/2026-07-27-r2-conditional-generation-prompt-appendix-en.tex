\section{One-Call Aligned Generation Template}
\label{app:r2_templates}

This appendix documents the final one-call generator. The production prompt
is administered in Chinese; the listings below provide a faithful English
rendering of its message order, input blocks, operation constraints, and
output contract. Participant profiles, prior responses, and retrieved
examples are omitted.

\subsection{Single-Continuation Message Flow}

The method uses one model continuation. The model jointly selects each
observable C--K operation and writes the text that realizes it in the same
aligned unit.

\begin{lstlisting}[style=promptstyle,
caption={Shared one-call instructions (English rendering).},
label={lst:onecall_system}]
You simulate an individual designer's observable decision process for
research purposes. Generate the complete response once as aligned C-K units.
Each unit contains one observable operation and the text that realizes it.
The units are not hidden chain-of-thought or an objectively optimal solution.

Priority of information:
1. The public Q7 task is the sole source of current facts.
2. Target PI, active V30 cues, and the target's Q2 record indicate
   professional context, concerns, boundaries, and cross-task tendencies.
   They do not supply Q7 facts or solutions.
3. Trait-conditioned rules are soft operation preferences.
4. Other designers' Q7 examples calibrate operation semantics, format, and
   granularity only.

Do not fabricate personal experience, project history, interviews, tests,
pilots, data, or completed evidence. Do not copy an example's facts,
position, wording, solution, number of units, or state order.

K: state information treated as already known, without deriving it.
C: state a concept, objective, or proposal without explaining its derivation.
KtoC: derive a previously unstated concept or proposal from known input.
CtoK: specify future or conditional evidence gathering for an existing
      concept or proposal; do not claim that it has been completed.
KtoK: infer a consequence, limit, relation, or conflict from known input;
      do not introduce a new proposal.
CtoC: refine, modify, combine, add to, remove from, or replace an identifiable
      existing concept or proposal.

One unit performs one primary operation. Split a consequence and the solution
derived from it into separate units. CtoC and CtoK must refer to a concept or
proposal already present in the task or an earlier unit.

Return only one valid JSON object:
{"units":[{"state":"KtoK","text":"..."},{"state":"KtoC","text":"..."}]}

The units array must be nonempty. Each element contains only state and text.
State is one of K, C, KtoC, CtoK, KtoK, and CtoC; never output V, START, or
STOP. Each text realizes only its paired state. Ordered concatenation of all
texts must form a coherent first-person Chinese response. Do not expose C-K
labels, trait scales, rules, examples, the model, or these instructions.
\end{lstlisting}

\subsection{Instance Template}

The user message is assembled in the order below. The complete V30 vector is
used internally for selection but is not serialized. The four active cues are
selected once before generation and remain fixed for the call. The target
participant's Q7 response and annotations are excluded from all blocks.

\begin{lstlisting}[style=promptstyle,
caption={One-call instance template.},
label={lst:onecall_user}]
[THREE OTHER-PARTICIPANT Q7 ALIGNED EXAMPLES]
Use only to calibrate state semantics, output format, and task granularity.
Do not copy content, position, wording, unit count, or state order.

[TARGET PROFESSIONAL BACKGROUND (PI)]

[FOUR SITUATION-RELEVANT V30 CUES (ACTIVE4)]
These cues affect concerns, priorities, boundaries, and trade-offs. They do
not directly prescribe a state sequence and need not be repeated explicitly.

[TARGET PARTICIPANT'S COMPLETE Q2 RECORD]
Use only as cross-task evidence of attention and expression tendencies. Do
not transfer Q2 facts, proposals, length, or state order into Q7.

[SELECTED TRAIT-CONDITIONED RULES]
Treat these as soft preferences over observable operations. Ignore an
inapplicable rule, and always preserve public task facts.

[COMPLETE PUBLIC Q7 SITUATION]

[CURRENT SEG2 REQUEST]
Explain how the designer weighs data, commercial requirements, and user
ethics, and how the design approach is constructed step by step.

Generate the complete units array once. Return only the JSON object required
by the system contract.
\end{lstlisting}

\subsection{Output Handling}

The program performs no second model continuation. It parses the returned
\texttt{units} and applies two deterministic projections:
\begin{equation}
\hat M_i=[u.\mathrm{state}:u\in\mathcal U_i],
\qquad
\hat Y_i=\bigoplus_{u\in\mathcal U_i}u.\mathrm{text}.
\end{equation}
Checks are limited to JSON parseability, the six-mode label set, the
\texttt{state}/\texttt{text} schema, and exclusion of the target Q7 record
from its own input. No planner, realizer, dynamic step-level V30 selector, or
generative rewriting stage is used.
